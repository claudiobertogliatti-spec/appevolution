# Editor Systeme.io — mappa verificata (17/9/2026)

Fonte: esplorazione diretta con screenshot di una copia del Template Master (interfaccia in italiano).

## Navigazione

- Funnel: Siti → Funnel. Menu `•••`: Visualizza, Duplica, Condividi, Disattiva, Impostazioni, Rimuovi. Per i partner si usa SOLO Condividi.
- Step: tab Configurazione del passaggio · Regole di automazione · Split test · Statistiche · Contatti · Totale vendite. Pulsanti: Visualizza il passaggio, Modifica Pagina, Cambia modello di pagina.
- Barra editor: Popup, Impostazioni, breadcrumb (Sezione > Riga > elemento), anteprima mobile, anteprima, Salvare, Esci.

## Scheda "Elementi"

Testo, Titolo, Bullet list, Casella del contenuto · Immagine, Video, Audio, Carosello · 4/3/2 colonne, Riga, Sezione · elementi di modulo, Pulsante, Casella di controllo, reCAPTCHA, Calendario · Pulsante di condivisione, Sondaggio · Conto alla rovescia, Menù, Linea orizzontale, Raw HTML, FAQ.

## Scheda "Blocchi"

Miei blocchi principali, Miei blocchi, Testimonianze, Page headers, Piani tariffari, Benvenuto, Membri del team, Moduli optin-in, Page footers, Caratteristiche.

## Impostazioni globali della pagina

Tipografia predefinita (font, dimensione, interlinea, colore link, colore testo, allineamento) · Heading typography (font, colore, allineamento) · Linguaggio · immagine social, nascondi dai motori · Tracciamento (evento Facebook, codice header, codice footer) · badge affiliazione Systeme (attivo di default: disattivarlo).

## Elemento Testo

Dimensione, interlinea, Tipo font (Google Fonts + famiglia), Tipo stile, Spaziatura lettere, margini, Allinea, ritardo di comparsa, visibilità Desktop/Mobile, attributi HTML.

## Sezione

Imbottitura, margine, colore sfondo, colore sfondo contenuto, Immagine sfondo (Upload), sezione fissa, ritardo, visibilità Desktop/Mobile, ID HTML.

## Note operative

- L'editor carica lentamente: attendere 8–10 s prima di interagire.
- Impostazioni elemento: icona ingranaggio sulla barretta arancione dell'elemento selezionato, oppure breadcrumb.
- "Esci" può non chiudere con modifiche non salvate: verificare con screenshot.
- `dashboard/page/<id>/edit` di una pagina di un altro account reindirizza alla Dashboard senza errore.
